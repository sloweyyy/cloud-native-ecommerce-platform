This page is the project's changelog for humans: a short list of engineering changes that matter, and what is planned next. The full, generated history is in <Src path="CHANGELOG.md" />, which semantic-release maintains.

## Planned

In rough priority order. Each item links to where the gap is described.

| # | Item | Why | Status |
|---|---|---|---|
| 1 | **Health checks and probes** | Map `/health/live` and `/health/ready` (packages are already referenced), add Kubernetes liveness and readiness probes | <span class="pill gap">not started</span> |
| 2 | **JWT authentication** | Validate the Azure AD B2C tokens the frontend already sends: Ocelot `AuthenticationOptions` plus `AddAuthentication().AddJwtBearer()` in services; replace the hard-coded `"system"` and `"slowey"` actors | <span class="pill gap">not started</span> |
| 3 | **Transactional outbox** | Reliable publish for Basket checkout and Catalog activity (the checkout consumer is already idempotent) ([Event bus](/building-blocks/event-bus/#delivery-semantics)) | <span class="pill partial">in progress</span> |
| 4 | **Observability depth** | Shared telemetry extension; MassTransit, EF Core, Mongo and Redis spans; OTel metrics that feed the business dashboards | <span class="pill gap">not started</span> |
| 5 | **.NET Aspire for local orchestration** | Replace the Compose-based inner loop with an Aspire AppHost (service discovery, dashboard with logs, traces and metrics) while keeping Compose and Helm for deployment | <span class="pill gap">exploring</span> |
| 6 | **Payment data hygiene** | Stop sending and storing card number and CVV; tokenize at the edge | <span class="pill gap">not started</span> |
| 7 | **Infrastructure convergence** | Pick one IaC path (Terraform), enable its remote state, align naming with CD, add an `apply` job with environment approvals | <span class="pill gap">not started</span> |
| 8 | **Strict mTLS and policies** | `PeerAuthentication` STRICT, sidecars for Ordering, `AuthorizationPolicy` per service, working NetworkPolicies | <span class="pill gap">not started</span> |
